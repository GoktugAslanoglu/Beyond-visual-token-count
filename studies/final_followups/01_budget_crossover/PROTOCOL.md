Every base case has a unique 10-uppercase-letter record key and seven-digit numeric answer. All irrelevant records use the same format; no highlighting. Keys and values are unique within a base stream. The same target and query persist across lengths. A prefix of the same distractor stream expands across lengths. ## Frozen analysis
Primary outcome is existing native single-answer case-insensitive containment (0/1), chosen for NIAH retrieval without making exact-output formatting the primary task. Also report canonical EM, literal EM and CER, never switch the primary metric based on outcomes.
Unit is base case, n=30. For each reader compute optical minus text at each length. Primary interaction = Delta_long - Delta_short. Two-sided exact sign-flip test of integer per-case interactions, obtained by enumerating the signed-magnitude distribution with dynamic programming. The null assumes conditional sign symmetry/exchangeability of case interactions; it is not an assumption-free test of any mean-zero distribution. Report this limit. Paired base-case bootstrap, 50,000 resamples, seed 202609230105; 95% percentile intervals, small fixed-design limitations. Holm over three reader interaction tests. Improvement supported only when effect positive, adjusted p<=.05 and interval lower bound>0.
Secondary LONG comparison uses two-sided exact McNemar/binomial test, separate Holm family of three readers and paired case bootstrap intervals. Optical advantage at LONG requires positive effect, Holm p<=.05 and lower CI>0. Intervals are pointwise, not multiplicity-adjusted.
Descriptive crossover requires Delta_short<0 AND Delta_long>0. Relative improvement alone is not crossover. Do not substitute a positive interaction for a positive LONG difference.

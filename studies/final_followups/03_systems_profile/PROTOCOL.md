## Timing instrumentation
Before every repetition synchronize CUDA, release prior request/output tensors, collect Python garbage, empty unused allocator cache, synchronize, record baseline allocated/reserved memory and reset peak statistics. This is a standardized cleared-allocator/resident-model regime, not a warm allocator steady-state deployment. Model/compiled-kernel loading is excluded; kernel caches may persist. CPU filesystem cache and thermal state are not controlled; record limitation.
Time rendering/representation materialization on CPU from frozen source plan, excluding source generation and protocol validation. Budgeted-text retention work is measured using exactly the frozen packing algorithm; full text construction is timed. Optical includes PIL rasterization/resampling; no disk image-read time is substituted for rendering. Measure native chat-template/tokenizer/image-processor preparation separately.
End-to-end starts before representation work and includes rendering/packing, template/processor, H2D, vision encoder, prefill and generation to one token, plus synchronization. Excludes model loading, audit validation, archive writing, network downloads and logging.
Use synchronized top-level model forward pre/post hooks: first forward time includes vision encoding and language-model prefill. Label it combined model prefill including vision, never pure language-decoder prefill. Record exactly how many top-level forwards occur. First-token timestamp obtained when the generation streamer receives first generated token, ignoring its initial prompt callback. Record model-start TTFT and pipeline-start TTFT; pipeline TTFT includes preprocessing. No extra forward pass solely to measure prefill.
Peak allocated/reserved GPU bytes include resident model weights, input transfers, vision and forward allocations. Report baseline and total peaks; not comparable across devices/backends. Wall clock perf_counter with explicit GPU synchronizations; hook/synchronization instrumentation overhead included equally. Do not report unavailable metrics as zero.
